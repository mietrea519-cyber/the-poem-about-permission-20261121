# The Poem About Permission

A short poem about agency — the power to ask, to be given, and to hand it back — written for the make.fun bounty [the-poem-about-permission-20261121-0235](https://make.fun/bounty/the-poem-about-permission-20261121-0235).

Run it with:

```sh

```

It writes the poem to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
